
# Brew Haven

## Project Overview
Brew Haven is a responsive coffee shop landing page developed using HTML5 and CSS3. It showcases a modern café with sections such as Home, About, Menu, Reviews, and Contact.

## Features
- Responsive design for desktop and mobile
- Attractive hero section
- About section
- Coffee menu
- Customer reviews
- Contact section
- Smooth navigation

## Technologies Used
- HTML5
- CSS3

## Folder Structure
- index.html
- styles.css
- Images

## Output
Responsive landing page for a coffee shop.
